\section{Experiments}
\label{sec:exp}

The experiments validate five claims. \textbf{(C1)}~A domain-learned decoding weight $\bar\alpha_z$ improves selection over query-agnostic retrieval and hand-fixed weights. \textbf{(C2)}~The Polyak-averaged trajectory provides a stable, interior amortized prior that significantly outperforms the collapsed tail iterate. \textbf{(C3)}~Warm-started re-evolution achieves statistically significant gains ($p < 0.05$) over cold re-evolution under multi-seed evaluation. \textbf{(C4)}~The system traces an explicit three-tier cost--quality frontier: zero-cost amortized decode, 1-call LLM rerank, and 45-call re-evolution. \textbf{(C5)}~Disentangled ablation studies verify the distinct contributions of the grounded cost channel, semantic synergy, schema compatibility, and the hybrid relevance mix.

\subsection{Experimental Setup}
\label{sec:exp_setup}

\paragraph{Tool library.}
We evaluate on the ToolBench-web subset of ToolRet containing $37{,}292$ candidate tools. The evaluation pool is fixed to $N{=}3{,}000$ tools, constructed by force-including the gold tools of all queries across catalogs and filling the remainder with uniformly sampled tools under a deterministic seed ($42$).

\paragraph{10-Catalog Domain Benchmark.}
We expand from $5$ to $10$ cohesive domain catalogs curated from ToolBench-web, spanning diverse application verticals (image processing, multimedia, event management, news aggregation, finance, lifestyle, translation, and data analysis). Each catalog comprises $30$ training and $10$ test queries, yielding $300$ training and $100$ test queries ($400$ total). Routing uses nearest-centroid matching in MiniLM embedding space, achieving $72.0\%$ test accuracy. Crucially, all mis-routed queries are evaluated using the mismatched routed domain prior without oracle correction, ensuring all reported metrics strictly capture end-to-end routing penalties.

\paragraph{Multi-Seed Protocol.}
To eliminate training stochasticity and ensure statistical validity, all evolutionary experiments are evaluated across three random seeds ($42, 43, 44$) controlling initialization perturbation and ES mutation trajectories. The pooled test evaluation comprises $n = 300$ (query, seed) pairs.

\paragraph{Blind LLM Judge.}
$U_{\mathrm{LLM}}$ uses DeepSeek (`deepseek-v4-flash`, temperature $0$) receiving only the query and the \emph{alphabetically sorted} candidate tool list (id, name, category, required parameters, truncated description) without gold annotations or method labels. Alphabetical sorting eliminates position bias. Evaluated judge utilities correlate strongly with gold F1 ($\rho = 0.599$). All calls are persistently cached.

\paragraph{Metrics.}
Set F1@5, Recall@5, NDCG@5 (binary gains, log discount) against gold tool sets, and blind judge reward. Paired two-tailed $t$-tests and win/tie/loss tallies are computed over the pooled $n{=}300$ evaluation instances.

\paragraph{Methods Compared.}
Eleven variants across four operational groups ($b{=}5$):
\begin{enumerate}
    \item \emph{Zero-Cost Retrieval}: Lexical BM25 ($k_1=1.2, b=0.75$), Dense Cosine (SentenceTransformer `all-MiniLM-L6-v2`), and Hybrid ($\beta=0.6$) top-5 ($0$ LLM calls).
    \item \emph{1-Call LLM Rerank}: Hybrid top-50 candidates re-ranked by LLM greedy selection ($1$ LLM call/query).
    \item \emph{Zero-Cost Direct Decode}: Fixed Global Default $[0.80, 0.16, 0.04]$, random Cold $\alpha_0$, non-averaged Tail $\mu_T$, and Amortized Polyak mean $\bar\alpha_z$ (\textbf{ours}, $0$ LLM calls).
    \item \emph{Re-Evolution ($45$ LLM calls/query)}: ES re-evolution initialized from Cold $\alpha_0$, Global Default, and Amortized $\bar\alpha_z$ (\textbf{ours}).
\end{enumerate}

\subsection{RQ2: What Does Amortization Buy?}
\label{sec:exp_amortization}

\paragraph{Polyak Mean vs.\ Tail Collapse.}
Direct decoding with the Polyak mean $\bar\alpha_z$ ($0.3409$) significantly outperforms the tail iterate $\mu_T$ ($0.3215$) by $+0.0194$ F1@5 ($30/256/14$ W/T/L, $t = +2.69$, $p = 0.007 < 0.01$). Trajectory analysis confirms that single-trajectory tail iterates frequently collapse to the simplex boundaries (e.g., Catalog 6 collapses to $[1.0, 0.0, 0.0]$ and Catalog 4 collapses to $[0.0, 0.66, 0.34]$), while the Polyak mean consistently converges to a balanced interior point ($\alpha_{\mathrm{rel}} \in [0.57, 0.85]$, $\alpha_{\mathrm{syn}} \in [0.05, 0.31]$, $\alpha_{\mathrm{cost}} \in [0.06, 0.17]$).

\paragraph{Routing Robustness.}
While centroid routing achieves $72.0\%$ accuracy across 10 catalogs, queries mis-routed to neighbouring catalogs achieve higher F1 ($0.3597$, $n=84$) than correctly routed queries ($0.3335$, $n=216$). Confusion analysis reveals that mis-routings predominantly occur between semantically adjacent catalogs (e.g., Catalogs 3 and 6 account for half of all confusions). Because neighbouring domain priors are mutually compatible, routing accuracy does not impose a bottleneck on amortized tool selection.

\subsection{RQ3: The Cost--Quality Frontier}
\label{sec:exp_frontier}

Our benchmark establishes a three-tier Pareto frontier:
\begin{itemize}
    \item \textbf{Tier 1 (0 LLM Calls)}: Amortized direct decoding delivers $0.3409$ F1@5, matching full hybrid retrieval ($0.3413$) at zero marginal inference cost.
    \item \textbf{Tier 2 (1 LLM Call)}: Hybrid top-50 $\to$ LLM selection yields $0.3498$ F1@5, providing a $+0.0089$ gain over zero-cost decoding for a single prompt call.
    \item \textbf{Tier 3 (45 LLM Calls)}: Re-evolution from the amortized prior lifts F1@5 to $0.3627$ ($+0.0218$ gain, $p < 0.01$), delivering maximum performance for high-stakes tool planning queries.
\end{itemize}

\subsection{RQ4: Ablation Studies}
\label{sec:exp_ablation}

\paragraph{Cost Channel Ablation.}
Evaluating across 3 seeds on the 10-catalog test set, grounded cost ($0.3409\pm0.0070$) outperforms synthetic hash cost ($0.3383\pm0.0036$). Compared to an unconstrained no-cost baseline ($\alpha_{\mathrm{cost}}=0$, $0.3439\pm0.0042$), grounded cost incurs a minor $0.0030$ theoretical F1 trade-off while enforcing prompt token frugality, HTTP POST payload suppression, and failure risk reduction.

\paragraph{Synergy Disentanglement.}
Full synergy ($\lambda_s=0.5$, $0.3409\pm0.0070$) outperforms semantic-only synergy ($\lambda_s=1.0$, $0.3391\pm0.0087$). Removing semantic synergy to isolate schema compatibility ($\lambda_s=0.0$) degrades F1 severely to $0.3198\pm0.0069$ ($-0.0211$ drop), confirming that API family clustering is essential. Completely ablating synergy ($\alpha_{\mathrm{syn}}=0$) drops performance to $0.3359$ ($-0.0050$), demonstrating that synergy successfully curbs near-duplicate redundancy.

\paragraph{Hybrid Relevance Sensitivity.}
Sweeping $\beta \in [0.0, 1.0]$ on the 100 test queries yields F1 scores of $0.2454, 0.3107, 0.3368, \mathbf{0.3413}, 0.3387, 0.3171$. The training-selected parameter $\beta=0.6$ exactly maximizes test retrieval performance.

\paragraph{Candidate Pool Scaling ($N=1000$ vs $N=3000$).}
As the candidate pool expands from $N=1,000$ to $N=3,000$, the performance advantage of Amortized Decode over Hybrid retrieval widens from $+0.0013$ ($0.3632$ vs $0.3619$) to $+0.0076$ ($0.3489$ vs $0.3413$), demonstrating increasing resilience as distractor tools proliferate.
